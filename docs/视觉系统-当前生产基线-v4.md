# 王玉个人网站视觉系统 · 当前生产基线 v4

> 状态：现行规范。更新时间：2026-08-10。
> 当前生产代码是最终事实来源；C 盘静态原型和 `docs/archive/` 中的文件只用于追溯设计过程。

## 1. 定位与原则

网站服务于招聘展示、作品证明与专业交流。视觉目标是建立克制的电影感、清楚的职业信息和稳定的个人识别，而不是制作赛车主题或通用 AI 科技模板。

核心原则：

- 影像先于装饰，Showreel 和真实媒体承担主要视觉冲击。
- 固定深色长页，不提供主题切换。
- 全站只使用一个品牌强调色，避免多色抢夺作品内容。
- 斜体 `WANGYU` 是唯一文字字标；王玉手写签名只在 Hero 标题后出现一次，不在页尾或其他区块重复。
- 项目文案必须说明需求、角色与使用状态，不把 AI 协作实现包装成独立手写全栈。

## 2. 当前页面结构

1. Hero：全屏海报与背景视频，标题“做影像，也整理方法。”从首屏中央随滚动缩放归位，玉青手写签名同步沿路径写出，并提供 Showreel 和项目入口。
2. Showreel：独立视频作品区，补充年份、时长和内容说明。
3. Selected Frames：从 60 秒 Showreel 提取八张代表帧；桌面纵向滚动驱动横向轨道，移动端、短屏和减少动态模式使用原生水平吸附。
4. Works：六个真实项目，展示状态、年份、描述、角色和标签；其中五项使用隔离或脱敏后的真实工具界面，“新光办事处”暂留抽象视觉。
5. Experience：2020 至今的职责按“影像制作 / 制作统筹 / 流程与 AI 工具”三幕推进，桌面使用短距离 sticky 叙事，其余环境静态展示。
6. Capabilities：四类能力与工具分组。
7. About：头像、职业经历、AI 协作方式。
8. Contact / Footer：发送邮件、复制邮箱、哔哩哔哩和完整邮箱地址。

当前页面不渲染 Marquee、主题切换或定制光标；手写签名只作为 Hero 的单次滚动视觉，不作为第二套站点字标。

## 3. 生产色板

| 角色 | 色值 | 当前用途 |
|---|---:|---|
| 主背景 | `#090B0D` / `#07090A` | 全站环境、区块、导航滚动态 |
| 暖纸白 | `#F2F1E9` | 主标题、正文、主要 CTA |
| 品牌玉青 | `#83E2CA` | 栏目编号、链接、焦点、按钮、邮箱标签 |
| 玉青悬停 | `#A6EFDD` | 强调色悬停与柔和状态 |
| 次级文字 | `rgba(242,241,233,.45—.75)` | 描述、标签、元信息 |
| 分隔线 | `rgba(255,255,255,.08—.18)` | 导航、卡片、章节边界 |

六个项目目前统一使用 `#83E2CA` 作为强调色。旧方案中的天空蓝、珊瑚粉、紫罗兰和薄荷绿不属于当前已启用的项目配色。

## 4. 字体与字标

- 自托管 Inter 加系统中文字体回退：`Inter, "Segoe UI", "PingFang SC", "Microsoft YaHei", Arial, sans-serif`，用于中文与英文主标题、按钮、正文和主要界面文字，复刻 C 版在当前设备上的观感，并保证不同设备的拉丁字形一致。
- Courier New / 微软雅黑：9—11px 的栏目编号、状态与元信息，沿用 C 版中英混排逻辑。
- Impact / Arial Narrow：斜体 `WANGYU` 字标和少量项目大编号。
- 联系邮箱沿用同一系统字体逻辑，使用 600 字重、正常字距并关闭连字，保证字符完整清晰。
- Georgia / Times 类衬线样式目前不是页面核心字体，不应在新组件中继续扩张。

字标规则：

- 固定显示 `WANGYU`，不加空格。
- 桌面约 31px，移动端约 27px。
- 默认暖纸白，悬停时变为玉青。

## 5. 布局与响应式

- 内容容器最大宽度为 1500px；桌面左右边距 36px，820px 以下为 14px。
- Hero、Showreel、Selected Frames、Works、Experience、Capabilities、About 和 Contact 均保持深色背景。
- Works 在 `xl` 断点下首组采用 8/4，后续采用 6/6；`lg` 下均为 6/6；移动端全部单列。
- Works 的多图项目在桌面通过 hover 交叉切换，在移动端改为原生横向滑动与 `scroll-snap`，并显示页码和进度点；单图项目不显示多余控件。
- 桌面联系邮箱靠右，移动端回到左侧；邮箱在常规宽度保持单行，在极窄视口或文字放大时允许安全换行，不得被裁切或造成页面级横向滚动。
- 所有长标题必须自然换行，页面不得出现水平溢出。

## 6. 影像、动效与性能

- Hero 先加载海报，再在非省流量、非慢速网络且未启用减少动态时延迟挂载背景视频。
- 正常网络下桌面与手机端都尝试静音、行内自动播放；若浏览器、低电量模式或系统策略阻止播放，继续显示海报并保留手动播放入口。
- Hero 离开视口、页面进入后台或用户手动暂停时停止播放。
- Showreel 使用 `preload="none"`，避免首屏同时下载约 60 秒视频。
- GSAP 用于必要的入场、Hero sticky 编舞、Selected Frames 横向轨道和 Experience 三幕推进；所有 pin 只作用于章节内部舞台，不包裹导航锚点。页内锚点沿用原生 `scroll-behavior: smooth`。
- Selected Frames 使用八张 1280×720 WebP，总体积控制在 400 KB 内；影集接近视口时预取，其他媒体继续按需加载。
- Selected Frames 在移动端使用卡片露边、吸附、双向手势提示、`01/08` 当前帧和百分比进度，明确传达仍可继续横滑。
- Works 的工具界面统一使用本地 WebP 与 `next/image` 懒加载；有第二张安全界面的项目可在桌面悬停时交叉切换，并在移动端通过横滑查看全部界面。
- Experience 在移动端使用位于固定导航下方的 sticky 章节条和滚入高亮来还原三幕推进；不 pin 内容、不拦截自然滚动，短屏与 `prefers-reduced-motion` 保持静态堆叠。
- 桌面最多同时保留 Hero、一个横向影集和一个短距离经历叙事；移动端、短屏与 `prefers-reduced-motion` 不使用滚动劫持或 pin。
- `prefers-reduced-motion` 下关闭非必要动画。

## 7. 导航与无障碍

- 桌面导航包含作品、项目、经历、能力、关于和联系。
- 页眉字号在桌面端为 13—14px，并根据当前章节持续显示玉青状态与下划线。
- 移动菜单使用 `dialog` / `aria-modal`，打开后锁定背景滚动并将主内容设为 `inert`。
- 移动菜单为底部安全区预留 `safe-area-inset-bottom`；导航、外链和 CTA 的方向图标统一使用 `currentColor` 内联 SVG，不使用可能被 iOS 渲染为彩色 Emoji 的 Unicode 箭头。
- 支持 Escape 关闭、焦点循环、关闭后恢复焦点和滚动位置。
- 保留“跳到主要内容”链接、语义化 `<main>`、清晰焦点样式和复制邮箱状态播报。
- 交互不能只通过颜色表达；链接同时使用下划线、边框、图标或位置变化。

- Hero、Showreel、Selected Frames 和头像已经使用真实媒体。
- Haitun Post Studio、即梦提示词助手、海豚后期公式生成、PPT2AE 与 Local AI Voice Lab 已使用隔离、虚构内容或空历史环境采集的真实界面；素材旁必须明确标识其演示属性。
- “新光办事处”尚未找到能够确认归属与授权的公开画面，继续使用抽象视觉，不得把 Showreel 中的候选镜头擅自归入该项目。

- 当前公开社媒只有哔哩哔哩。
- 尚无公开简历 PDF 和下载按钮。
- 不在公开仓库记录内部后台、同事姓名、训练素材名称、硬件清单、模型权重体积或其他仅用于本人核验的信息。
