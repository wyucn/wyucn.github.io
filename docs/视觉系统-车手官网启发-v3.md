# 王玉个人网站视觉系统 v3

> 2026-08-07 实施说明：正式站继续以本文的编辑感、影像主导和非对称网格为原则，同时再次合并 C 盘静态原型的视觉优点。当前生产实现采用深色电影感长页、8/4 + 6/6 六项目视觉网格、斜体 `WANGYU` 字标，以及桌面端靠右且不拆行的清晰邮箱展示。下文的纸白章节节奏保留为研究基线，不再要求逐段机械照搬。

## 目标

以 C 盘误创建的静态原型为主基线，重新吸收 Charles Leclerc 与 Lando Norris 官网的视觉原则。目标不是做赛车主题，而是建立具有编辑感、影视感和强个人识别的作品网站。

## 核心判断

参考站的高级感并不来自“赛车配色”，而来自：

- 首屏只有一个明确视觉重心；
- 极大的展示字体与少量高反差衬线体混排；
- 暖白与近黑之间的大面积硬切；
- 单一高饱和强调色严格控制面积；
- 不同章节之间形成安静—高能—安静的节奏；
- 图片尺度不统一，使用错位与非对称网格，而不是等宽后台卡片。

玉青只承担品牌动作与关键状态，不用于大段正文。项目辅助色只存在于各自的视觉画面中，不进入全站导航和正文系统。

## 页面节奏

1. Hero：暖纸白技术网格、超大 `MOTION × AI`、Showreel 入口。
2. Marquee：实心玉青信息带，形成第一次高能切换。
3. Showreel：纯黑放映厅，作品画面为主角。
4. Works：暖纸白非对称 12 栏项目网格。
5. Experience：纯黑大年份板与职责列表。
6. Capabilities：暖纸白硬线 2×2 能力网格与工具分组。
7. About：玉青外场包裹黑色顶部缺口面板。
8. Contact：纯黑大字 CTA 与玉青联系动作。

## 字体规则

- 英文展示字使用 Impact / Arial Narrow 类窄粗体，仅用于大标题、年份和项目编号。
- 衬线体使用 Georgia / Times New Roman，仅用于标题中的一个短语。
- 中文正文继续使用清晰的系统黑体，不强制压窄。
- 展示标题使用紧行高和负字距；正文保持 1.6—1.8 行高。

## 组件规则

- 导航固定使用暖纸白毛玻璃，不再提供主题切换。
- 取消定制光标、全页噪点、彩色渐变字和永久漂浮动画。
- Hero 只保留一次进入动画，不做持续旋转或光球动画。
- Marquee 使用实心玉青底和墨黑文字，不使用空心描边大字。
- 项目首屏采用 8/4 网格，后续采用 6/6；移动端全部单列。
- 卡片正文保持暖纸白，项目视觉保持深色并拥有独立辅助色。
- 移动端左右边距为 14px，所有长标题必须自然换行且禁止页面级横向滚动。

## 参考边界

- 不使用车手姓名、赛车号码、车队标志、赛车素材或其品牌字体。
- 不复制 Ferrari 红、McLaren 青柠或赛车几何结构的具体组合。
- 借鉴的是色彩克制、排版尺度、图像主导和章节节奏。
