# 个人网站重设计整合说明

> 本文记录整合过程。当前正式方向不是在 C / D 两版之间二选一，而是保留 D 盘 Next.js 正式站的工程、内容与无障碍基础，同时吸收 C 盘静态原型更强的斜体 `WANGYU` 字标、项目编排、联系区邮箱布局和移动端节奏。

## 背景

2026-08-06 的几轮设计工作误落在 `C:\Users\MWANG\Documents\个人网站`，没有进入正式仓库 `D:\wyucn.github.io`。误落目录包含一套纯静态视觉原型、招聘文案审阅稿和最终配色规范。

本次不直接覆盖正式仓库，而是保留 Next.js、SEO、静态导出和部署结构，将有效设计决策逐项移植。

## 参考站提炼

视觉研究参考：

- Charles Leclerc 官网：强识别首屏、超大排版、内容分区与赛事海报感。
- Lando Norris 官网：粗细字体对比、几何容器、卡片节奏与年轻但克制的互动感。

只吸收设计原则，不复制品牌素材、专有版式或交互实现。

## 已整合的设计决策

- Hero 改为“做影像，也整理方法。”，用更直接的职业判断代替通用科技口号。
- 将 Showreel 视觉预览并入 Hero，让首屏同时建立职业定位和真实作品入口。
- Showreel 继续位于 Hero 后，优先证明视频与动态视觉能力。
- 保留六个真实项目、工作经历、能力与 About 内容，不回退为虚构卡片或纯视觉占位。
- 采用固定深色视觉，以墨黑承载影像与内容，以明亮玉青统一品牌、CTA、焦点和交互状态。
- 移除深浅主题切换，减少视觉分叉和客户端状态，让正式站保持稳定的电影感长页体验。
- 保持移动导航滚动锁定、键盘退出、隐藏链接不可聚焦等可访问性处理。
- 恢复“跳到主要内容”入口与 `<main>` 语义，方便键盘和辅助技术用户。
- 恢复复制邮箱、成功提示和剪贴板不可用时的降级复制。

## 没有直接移植的内容

- 纯静态原型的 `index.html`、`styles.css`、`main.js` 和自建服务器没有进入生产目录，避免形成第二套无人维护的实现。
- 原型中的荧光绿、蓝紫项目色与大面积纸白首页没有沿用，因为它们与最终配色规范冲突。
- 没有重复复制头像、Showreel 封面与视频；正式仓库已有内容相同的媒体文件。

## 后续内容优先级

1. 为六个项目补真实封面、截图或短视频，而不是继续依赖 CSS 示意图。
2. 为项目增加职责、过程、约束和结果证据；至少先完成 Haitun Post Studio 与“新光办事处”。
3. 补充可公开的 PDF 简历，并在 Contact 区增加下载入口。
4. 确认除 Bilibili 外可公开的社交主页或作品平台。
5. 评估是否需要独立项目详情页；若内容不足，先保持单页，避免空详情页。
