# 王玉个人网站配色规范

> 历史方案，已于 2026-08-06 停用。用户实测认为该方案缺少参考站的冲击力且整体观感不佳。当前生产方向改为“暖纸白＋墨黑＋明亮玉青”的固定视觉系统，详见 `视觉系统-车手官网启发-v3.md`。

## 1. 最终结论

本网站采用 **「墨海玉青 · 朱砂点火」** 作为最终配色方向。

- 个人识别色：**玉青 `#3A9C8B`**
- 网站环境底色：**墨海蓝黑 `#0C1721`**
- 动态强调色：**朱砂橙 `#E25B3F`**
- 核心原则：**木为主、水为底、火作点睛**

这套方案是针对以下定位得出的首选，而不是通用模板：

- 姓名：王玉，“玉青”能够形成自然、长期可用的个人记忆点。
- 职业：视频后期、Motion Design、AIGC 与 AI 创意工作流。
- 网站目的：招聘展示、作品证明、专业交流。
- 品牌气质：可信、务实、克制、有创意，但不包装成泛化的“AI 专家”。
- 传统文化参考：八字中金有根、火明显、木不显，因此以青绿色为主、深蓝黑承载、朱砂少量点睛。命理仅作为文化审美参考，不代替设计与可用性判断。

不采用常见的“霓虹紫＋电光蓝”AI 配色，因为辨识度较低，也会削弱视频后期与真实工作流的专业质感。

## 2. 核心色板

| 设计角色 | 名称 | 色值 | 建议占比 | 主要用途 |
|---|---|---:|---:|---|
| 页面背景 | 墨海蓝黑 | `#0C1721` | 55% | 页面底色、Hero、Showreel、页脚 |
| 内容表面 | 深青岩 | `#142632` | 23% | 导航、卡片、项目说明、弹层 |
| 主文字 | 暖象牙白 | `#F4F0E8` | 10% | 标题、正文、重要数据 |
| 次级文字 | 雾灰青 | `#B8C5C8` | 4% | 描述、元信息、时间与分类 |
| 个人品牌色 | 玉青 | `#3A9C8B` | 6% | 姓名、Logo、栏目编号、链接、AI/Workflow 标签 |
| 动态强调色 | 朱砂橙 | `#E25B3F` | 2% | 播放按钮、主要 CTA、当前状态、时间轴关键帧 |

比例是视觉控制原则，不要求逐像素精确统计。玉青与朱砂合计不宜长期超过页面面积的 10%。

## 4. 页面区域分配

### 导航

- 默认透明或使用 `rgba(12, 23, 33, 0.86)` 毛玻璃背景。
- 姓名或个人标记使用玉青。
- 导航文字使用暖象牙白；悬停时改为玉青。
- 当前页面可使用 2px 玉青下划线，不使用整块高饱和背景。

### Hero

- 背景以墨海蓝黑为主，可加入非常克制的玉青径向光晕。
- 姓名“王玉”或标题中的一个关键词使用玉青，其余标题保持象牙白。
- “观看 Showreel”作为主要 CTA，使用朱砂橙实心按钮和墨海蓝黑文字。
- “查看 AI 实践”作为次要 CTA，使用玉青描边或文字按钮。
- 不建议整行渐变文字，也不建议同时出现紫、蓝、青、橙多色霓虹。

### Showreel

- 视频画面本身是视觉主角，外围保持墨海蓝黑。
- 播放按钮使用朱砂橙；进度、分类或悬停描边使用玉青。
- 视频缩略图不统一套重度色罩，避免破坏作品原色。

### Selected Work

- 卡片背景使用深青岩 `#142632`。
- 项目编号、类别和 AI/Workflow 属性使用玉青。
- 只有最重要的推荐项目、播放入口或当前选中状态使用朱砂。
- 卡片悬停优先采用轻微上浮、玉青描边和阴影变化，不把整张卡片染成品牌色。

### Experience / About

- 以暖象牙白和雾灰青保证长文本阅读。
- 时间轴线使用低透明度灰青；关键节点可用玉青。
- 朱砂只用于当前职位、重要数字或少量强调，不用于整段正文。

### Contact

- 最终联系按钮可以再次使用朱砂橙，形成首尾呼应。
- 邮箱、复制成功状态及辅助链接使用玉青。
- 页脚回到墨海蓝黑，不另外增加新的品牌色。

## 5. 无障碍与文字颜色规则

已核对的主要对比度：

| 组合 | 对比度 | 结论 |
|---|---:|---|
| 暖象牙白 `#F4F0E8` / 墨海 `#0C1721` | 15.93:1 | 适合所有正文与标题 |
| 雾灰青 `#B8C5C8` / 墨海 `#0C1721` | 10.22:1 | 适合次级正文 |
| 玉青 `#3A9C8B` / 墨海 `#0C1721` | 5.44:1 | 可用于普通字号文字 |
| 玉青 `#3A9C8B` / 深青岩 `#142632` | 4.66:1 | 可用于普通字号文字 |
| 朱砂 `#E25B3F` / 墨海 `#0C1721` | 5.00:1 | 可用于普通字号文字 |
| 朱砂 `#E25B3F` / 深青岩 `#142632` | 4.29:1 | 仅用于大字、粗体或装饰 |
| 正文链接 `#4FB7A2` / 深青岩 `#142632` | 6.38:1 | 适合卡片内普通字号链接 |
| 深玉青 `#176B63` / 宣纸白 `#F5F1E8` | 5.61:1 | 适合浅色模式普通文字 |
| 浅色次级文字 `#5E6966` / 宣纸白 `#F5F1E8` | 5.05:1 | 适合浅色模式次级正文 |

强制规则：

- 玉青或朱砂实心按钮必须使用墨海蓝黑文字，不使用白色小字。
- 深青卡片上的小号橙色文字改用 `accent-readable #E86649`。
- 深青卡片上的小号正文链接使用 `link-on-dark #4FB7A2`，品牌原色优先用于 Logo、标签与较大文字。
- 玉青与朱砂彼此对比度很低，不能把两者相邻使用来单独区分类别，也不能互相作为文字与背景；必须配合标签、图标或形状。
- 墨海背景与深青卡片的明度差较小。普通卡片可以依靠留白和弱边框，但输入框、筛选器和按钮等可交互控件必须使用 `border-control #5A7580`。
- 深色模式的雾灰青 `#B8C5C8` 禁止直接搬到浅色背景；浅色次级文字使用 `#5E6966`。
- 不只依靠颜色表达状态；同时使用图标、下划线、描边或文字标签。
- 正文禁止使用低透明度玉青或朱砂。
- 焦点状态必须清晰，推荐使用 2px 暖象牙白外环加 2px 间距。

## 6. 渐变、光效与动效

### 推荐

- 墨海背景叠加单一玉青柔光，透明度控制在 8%—14%。
- 朱砂光效只围绕播放按钮、CTA 或时间轴关键节点出现。
- 悬停动效采用描边变亮、轻微位移和短暂光晕，不使用持续闪烁。
- 转场可从墨海过渡到深青岩，保持影视暗场质感。

背景示例：

```css
background:
  radial-gradient(
    circle at 76% 18%,
    rgba(58, 156, 139, 0.14),
    transparent 34%
  ),
  #0c1721;
```

### 禁止

- 禁止制作玉青到朱砂的大面积直接渐变，容易产生浑浊感。
- 禁止将紫色、荧光蓝加入核心色板。
- 禁止大面积发光描边、赛博网格或高频粒子背景。
- 禁止对所有项目封面统一使用同一种彩色滤镜。

## 9. 浅色页面规则

主站保持深色。只有以下场景建议使用浅色：

- 简历预览与打印版
- 长篇文章或项目复盘
- 需要大量连续阅读的知识内容

浅色模式使用：

- 背景：`#F5F1E8`
- 卡片与正文容器：`#FFFDFC`
- 强分区面板：`#E7E2D7`
- 正文：`#182321`
- 次级正文：`#5E6966`
- 品牌色：`#176B63`
- 强调色：`#AE4E34`

浅色模式不要直接使用亮玉青 `#3A9C8B` 作为小号正文，也不要复用深色模式的雾灰青 `#B8C5C8`，因为它们与浅背景的对比度不足。

## 10. 搭建时的执行指令

> 请严格按照“墨海玉青 · 朱砂点火”配色搭建，不要自行替换成常见 AI 紫蓝风。以 `#0C1721` 作为全站环境底色，`#3A9C8B` 作为王玉的个人品牌识别色，`#E25B3F` 只用于播放、主要 CTA 和少量关键状态。作品画面应保持原色并成为视觉主角，界面颜色负责承载与组织，不与作品争夺注意力。优先保证招聘阅读效率、作品展示和无障碍对比度，避免霓虹、重度渐变、满屏发光与大面积高饱和色。

## 11. 验收标准

- 第一眼具有影视暗场质感，但不会像游戏或赛博朋克页面。
- 姓名、Logo 与关键栏目能够稳定建立“玉青”记忆。
- 朱砂只形成视觉焦点，不抢夺作品内容。
- Showreel、项目图片和视频仍是页面最醒目的内容。
- 页面在深色环境下连续阅读舒适，正文与交互状态对比清楚。
- 去掉所有项目图片后，界面仍然具有统一、克制、可识别的个人气质。
- 不新增核心品牌色；确需状态色时，优先通过明度、透明度、图标与文字解决。
